# 無限電影館製作計畫

## 目的與範圍
提供可探索的森林、大西洋海岸、秋日步道與雪林，讓使用者短暫休息。採單頁原生 HTML、CSS、JavaScript，不增加前端套件。影像為 AI 生成自然景色，加上第一人稱視線移動、動態粒子與程式合成音景，不冒稱實地錄影。

## 實作與完成判準
1. 建立四個場景素材與來源記錄；以森林為首屏。
2. 實作場景切換、播放／暫停、聲音與音量、全螢幕、休息計時、收藏及呼吸練習。
3. 支援滑鼠／觸控視線探索、鍵盤、手機排版與減少動態偏好。音訊須由使用者主動開啟。
4. 由獨立代理審查與瀏覽器驗證；至少測四景切換、暫停、音量、計時、呼吸與窄螢幕。
5. 保存原始檔、使用說明與驗證結果；建立版本與私密網站，確認部署成功後交付網址。

## 派工
- 素材代理：僅擁有 assets/ 四景素材與影像來源說明，不修改網頁。
- 查核代理：查核記憶路由、Sites 流程、Context7 原生 API 文件，不修改檔案。
- 驗收代理：完成後以新上下文審查原始碼與實際操作，不以製作者的口頭結論代替測試。

## 限制與風險
靜態影像的視線移動無法呈現真正走路的視差或原始影片。合成音景與實地收音有差異。WebGL、音訊與全螢幕依瀏覽器能力提供降級與錯誤提示。未連接校務資料或資料庫。
