# nature-v2 修正紀錄（2026-10-24）

> 來源：2026-10-24 的程式審視與 E2E 驗收找到 8 個問題（P1～P8）。本次只改 `app.js`、`engine.js`、`style.css`，沒有動 `classic/`、素材與 `vendor/`。

## 修正內容

| 編號 | 問題 | 修法 | 位置 |
|---|---|---|---|
| P1 | WebGL 執行中失去 context，退回靜態版後按「試試 3D」會沿用失效畫布，three.js 讀不到 shader 精度而丟例外，只能重新整理頁面 | 退回靜態版時就換一張新畫布；從 bfcache 還原時也先換新畫布再建立 | `app.js` 的 `useClassic`、`pageshow` |
| P2 | WebGPU 渲染器建立時丟例外，引擎先呼叫 `onFailure`，頁面直接切到靜態版，沒有照說明改走 WebGL | WebGPU 建立期間引擎回報的失敗先不降級；建立失敗或建好但未就緒，一律釋放後換新畫布改走 WebGL | `app.js` 的 `start3D` |
| P3 | 漫步中退回靜態版後按「試試 3D」，操作提示、控制列、準星殘留在首頁 | `useClassic` 比照 `leaveWalk` 收起這四個元素 | `app.js` 的 `useClassic` |
| P4 | 全螢幕只顯示舞台子樹，提示框在舞台外，全螢幕時看不到 | `fullscreenchange` 時把提示框搬進全螢幕元素，離開時搬回 `body` | `app.js` |
| P5 | 漫步中開著對話框按 Esc，對話框關閉的同時也結束漫步 | 有開著的對話框時，Esc 只交給對話框 | `app.js` 的 `keydown` |
| P6 | 漫步時提示框（`bottom:83px`）蓋住控制列（`bottom:100px`） | 漫步時提示框移到畫面上方（`top:76px`） | `style.css` |
| P7 | 兩條管線都讀 `renderer.info.render.calls`；WebGPU 渲染器的這個值是啟動以來的 render 次數，回報的 draw calls 會一直累加 | WebGPU 改讀 `renderer.info.render.drawCalls`（每幀值），WebGL 不變 | `engine.js` 的 `onStats`、`getState` |
| P8 | 降級訊息出現「。。」雙句號；引擎訊息寫「輕量版」，介面其他地方都叫「靜態版」 | 引擎訊息結尾已有句號時不再補；「輕量版」統一為「靜態版」 | `app.js`、`engine.js` |

## 重跑方式

1. 在 repo 根目錄啟動靜態伺服器：`python -m http.server 4174 --bind 127.0.0.1`。
2. 執行 `node nature-v2/tools/E2E驗收.cjs <輸出資料夾>`；只跑回歸項目時設環境變數 `ONLY=回歸`。
3. `python nature-v2/tools/E2E摘要.py <輸出資料夾>/結果.json` 產生表格。

腳本預設 `require('playwright')` 與系統 Chrome；Playwright 不在模組搜尋路徑時用 `PLAYWRIGHT_PATH` 指定位置，另可用 `CHROME_PATH`、`NATURE_URL` 覆寫。

## 限制與未處理

- 審查時列為低優先的項目這次沒有改：雪景字幕對比、320px 標題斷字、鳥鳴計時在換新 AudioContext 後不重設、多指轉頭與右鍵轉頭、重複點同一景會重建、`engine.js` 部分初始化在 try 之外、`gpu.js` 的反向 `smoothstep`（Chrome 156 未重現問題）。
