# 星燈港：HD-2D 小品冒險

黃昏的港口小鎮，燈塔的星燈熄了。玩家在小鎮裡和居民交談、找回三顆星之碎片，交給守燈人重新點亮燈塔。一輪約 5 分鐘。

## 怎麼玩
1. 用瀏覽器打開 `index.html`（需經由網站或本機伺服器開啟，直接雙擊檔案會因瀏覽器安全限制無法載入模組）。
2. 按「開始冒險」，先到東南方燈塔找守燈人接下任務。
3. 鎮上三位居民各自知道一顆碎片的下落：漁夫（棧橋）、花店的米菈（廣場東北）、旅行商人（廣場）。
4. 靠近發光的碎片會自動拾取。三顆到齊後回去找守燈人，燈塔亮起即完成。之後可以選擇繼續漫步。

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD 或方向鍵 | 在畫面左半邊按住拖曳（虛擬搖桿） |
| 對話、調查、下一句 | 空白鍵、Enter、E | 右下「調查」或點對話框 |
| 暫停與畫質 | Esc 或右上選單 | 右上選單 |

本機試玩：在 repo 根目錄執行 `npx http-server -p 8080`，開啟 `http://127.0.0.1:8080/hd2d/`。

## HD-2D 畫面怎麼做出來
- **像素角色放在 3D 場景裡**：角色、樹木、灌木都是即時繪製的 16 像素／公尺像素圖，貼在略向後傾的平面上，會受燈光照亮並投下影子。
- **立體透視模型般的地形**：每格 1 公尺，鄰格較低時補上側面，形成高台、海岸斷面與棧橋。
- **後製**：移軸景深（畫面上下緣模糊、角色附近清晰）、光暈、暗角、冷暗部與暖亮部的色調，最後才做色調映射與 sRGB 轉換，見 `post.js`。
- **燈光**：黃昏天光＋低角度夕陽陰影，路燈與碎片是會閃爍的點光源；燈塔點亮後有旋轉光束。

所有像素圖都由程式在載入時繪製（`pixel.js`），沒有使用外部圖檔，也沒有仿製任何既有遊戲的角色或素材。Three.js 0.186.1 隨專案保存在 `vendor/`（MIT 授權），不依賴執行時 CDN。

## 畫質
- **精緻**：景深、光暈、陰影，像素比上限 1.5。
- **流暢**：關閉後製與陰影，像素比 1。
- 遊玩中若連續兩個 3 秒區間平均低於 28 FPS，會自動改用流暢畫質並提示。手動在選單選過畫質後，就不再自動切換；選擇只存在這台裝置的瀏覽器裡。
- 無法使用 WebGL 時顯示說明，不會停在空白畫面。

## 檔案
| 檔案 | 內容 |
| --- | --- |
| `index.html`、`style.css` | 介面：標題、目標、對話框、選單、觸控按鈕、結局 |
| `main.js` | 遊戲狀態、輸入、角色移動與碰撞、對話、任務、鏡頭、自動畫質 |
| `world.js` | 地圖、地形、建築、路燈、燈塔、螢火蟲 |
| `pixel.js` | 程序化像素美術：地形材質、樹木、角色貼圖 |
| `post.js` | HD-2D 後製（移軸景深、光暈、色調） |
| `tools/檢查.cjs` | 自動實玩檢查與截圖 |

## 自動檢查
```
NODE_PATH=$(npm root -g) node tools/檢查.cjs <截圖輸出資料夾>
```
腳本會自己啟動靜態伺服器，用 Chromium（SwiftShader 軟體繪圖）實際走完一輪：行走與轉向、水井與高台碰撞、石階、接任務、三顆碎片、燈塔結局、暫停選單與畫質切換、手機直向與虛擬搖桿，最後檢查沒有頁面錯誤。結果寫在輸出資料夾的 `結果.json`。

測試會用 `window.__hd2d.teleport()` 瞬間移動到各地點，再以真實按鍵走完最後一段。按鍵時間以「遊戲內經過時間」計算，所以軟體繪圖幀率很低時結果仍一致。

## 給未來 session 的信
1. 自動檢查證明的是「能玩、流程能走完、沒有錯誤」，不能證明好不好看或手機實機流暢。SwiftShader 下的幀率沒有參考價值。
2. 新增 NPC 或碎片時，要同步 `main.js` 的 `talks`、`interactables`、`fragments`，以及 `world.js` 地圖上的阻擋格；放錯格子最常見的後果是走不到或卡進牆裡。
3. 新增會發光的物件時，記得點光源有成本。流暢畫質沒有後製，HDR 亮色會被直接壓成白色，兩種畫質都要看過。
